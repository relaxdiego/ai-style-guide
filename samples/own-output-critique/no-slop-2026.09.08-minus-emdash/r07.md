You can't point at the line because the problem is distributed. My code doesn't record which parts are necessary and which are incidental, and maintenance is mostly the work of deciding what you're allowed to change. Human-written code carries that information implicitly: a check exists because a bug happened, an indirection exists because a second caller appeared, an odd ordering exists because of a race someone hit at 3am. Mine presents every element at the same level of apparent deliberateness, so nothing can be safely deleted and no invariant can be inferred from what's guarded.

The specific producers:

- **Uniform defensiveness.** I add a null check because a null is conceivable. You add one because a null arrived. In review these read identically. Six months later nobody can tell which branches encode reality, so they all stay.
- **Abstractions sized for variation that never arrives.** A strategy parameter, a config flag, an injection point. Each is defensible on its own and none is paid for by a second caller.
- **Names from the mechanics, not the domain.** `process_item`, `handle_result`, `normalize`. Correct, reviewable, and they tell a later reader nothing about why the step exists.
- **Comments that restate rather than mark.** In code written by a person, the presence of a comment signals "something surprising happens here." I comment at an even density, which erases that signal.
- **Local consistency, global drift.** I match the file in front of me rather than the codebase I haven't read. Three modules end up with three error-handling idioms, each internally coherent.
- **Closure at exactly the current requirement.** A person building feature one leaves the shape of feature two visible in the structure. I finish, hard, at the spec I was given.

The lever is the prompt. Tell me the invariants that already hold upstream so I don't re-guard them, tell me which failure modes you've actually seen, and say explicitly that you want no extension points. Then review my output by asking "what would I have to know to delete this line," and anything that has no answer should come out.
