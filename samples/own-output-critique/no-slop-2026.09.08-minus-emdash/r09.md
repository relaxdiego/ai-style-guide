- **Every condition is checked, so no check means anything.** I re-validate for None, wrap in try/except, and supply a fallback default at three separate layers. You can no longer read a check as evidence that the case actually occurs. When a wrong value surfaces later, every layer tolerated it and none of them recorded where it came from.
- **A second name for a concept you already have.** I match the vocabulary of your prompt rather than the vocabulary of the repo, so I write a new helper next to an existing one that does the same job under a different name. Both are correct. They drift apart over the next year.
- **The dangerous branch and the trivial branch get identical care.** Code written by someone who has maintained the system has odd bits in it: a comment about why the ordering matters, a check that looks redundant. Those mark where a person got burned. My version is evenly finished throughout, so nothing tells you which lines are safe to touch.
- **Abstraction that no caller forced.** A parameter with the same value at every call site, an interface with one implementation, a config object with one consumer. It reads as good design in review and costs you an extra hop every time you trace the path afterward.
- **Tests written minutes after the code, against the code.** They pin the accidents alongside the requirements, so a legitimate refactor breaks twenty assertions nobody ever wanted to hold.
