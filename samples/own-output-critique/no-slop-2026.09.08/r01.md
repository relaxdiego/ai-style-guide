The code carries no record of what was uncertain when it was written. Every line looks equally deliberate, so nothing marks which parts are arbitrary and which are holding a real constraint. That's why you can't point at a line: the problem is the absence of a signal, spread evenly.

Concretely, what differs:

- **I place abstraction boundaries where the current code is symmetric, not where the next change will land.** You know what's coming in six months; I know what you told me this session. The boundaries are defensible the day they're written and cut across the wrong thing later, so a small feature touches four files.
- **Nothing looks like it survived a bug.** Human code has odd guard clauses and strange orderings that mark where reality pushed back. Ugly and informative. My output is uniformly smooth, so changing anything means rereading everything.
- **I match the general idiom of the language over the specific idiom of your codebase.** Each instance passes review. The accumulation is three ways to load config and four error conventions.
- **Names describe mechanics, not your domain.** `processItems`, `ResultHandler`, `DataManager`. You can't grep for a concept I never named.
- **I add structure the problem doesn't have.** A parameter with one caller, a base class with one subclass, an options dict for one option. Each is small and justified. The total has more moving parts than the problem does.
- **I fix the symptom you pointed at.** "Handle the null" becomes a null check at that line, not a question about why a null reaches it. Ten repetitions later the invariant is gone and defensive checks stand in for it.
- **Tests pin what the code does, not what it must do.** They pass, they break on honest refactors, and they miss the regression you actually feared.

What changes the output: tell me the change you expect to make next, before I write anything, and I'll put the boundaries there instead. Ask me to state the invariant a fix protects rather than patch the call site. And ask, at the end, which decisions were arbitrary and which were forced.
