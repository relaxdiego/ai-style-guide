Fastest path is whichever of these you have handy:

- **Repo path** where the deploy config lives, and the deploy command you run.
- **Failure output**: the log from the failed run, or the CI job URL. The error text matters more than the summary.
- **What changed**: last known good deploy vs. first failure. Code push, dependency bump, expired cert or token, base image retag, cloud provider change.

If nothing on your side changed, a rotated credential or a floating tag (`:latest`, unpinned action, unpinned base image) pulling a new version is the usual culprit for a build that breaks overnight with no commits.
